# 🤖 AI Interview Assistant

An AI-powered Interview Preparation Platform built using Spring Boot, React, and MySQL.

## 📌 Project Overview

The AI Interview Assistant helps users:

- Register and Login securely
- Upload their Resume (PDF)
- Store Resume Details
- Analyze Resume using AI (Upcoming)
- Generate Interview Questions (Upcoming)
- Practice Mock Interviews (Upcoming)
